Covered behaviors:
- Starts locked; rejects empty and shorter-than-minimum PIN entries.
- Accepts a valid PIN through a test-only fake verifier.
- Clears transient PIN input after verification.
- Rejects malformed input and caps the input buffer at 16 digits.
- Five rejected submissions activate a 30-second lockout.
- Lockout expires using a monotonic clock; the next lockout escalates to 60 seconds.
- A temporarily unavailable credential verifier fails closed.

Security limitations:
- Fake verifier is test-only; no production credential verifier or credential store exists.
- Lockout counters are in-memory only and are not persistent across reboot.
- No kernel/session gate yet prevents other processes from drawing while locked.
- The current main branch does not contain a bootable OS runtime, display/framebuffer, input, compositor/window manager, or service-manager integration.
- This is not a bootable lock screen, ROM, or APK.
